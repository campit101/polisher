# Upwork portfolio entry

## Title

Polisher: AI drafts rewritten in your voice, Stripe and Supabase

## Description

I led the making of Polisher, a web app that takes an AI draft and gives it back in the writer's own voice. You paste 3 to 5 samples of your own writing, then a draft, and a rule-based clean-up step strips AI habits such as long dashes and stock phrases and enforces British or American spelling. A meaning check flags any number, link or quotation that changed.

It ran as a real £5-a-month product with success and failure numbers fixed before launch. It drew 143 front-page views and no payments, so I called it a fail, stopped selling and turned it into this demo. Nobody was charged.

Now it runs on Stripe test mode only, enforced in code, with one-press throwaway demo accounts. Rewrites use Claude Haiku 5.5 inside a hard shared budget of about £0.10 a day. It uses Next.js, Supabase and Vercel, and 1,600 unit, 73 integration and 200 browser tests pass.

## Skills

Next.js, TypeScript, Supabase, PostgreSQL, Stripe, Tailwind CSS, Playwright, Vercel, Claude API
